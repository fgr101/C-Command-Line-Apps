## Wallet Comparison Program (WalletCompare.c)

*This is a C program that allows users to input exchange rates between Brazilian Real (BRL) and Tether (USDT) for up to 4 different banking/fintech apps. The program then generates a report showing the app that offers the best exchange rate.*

**Key features:**

Allows users to input the app name, BRL received, and USDT received for up to 4 apps.
Calculates the BRL to USDT and USDT to BRL exchange rates for each app.
Identifies and displays the app that provides the best USDT to BRL exchange rate.
Saves and loads user data to/from a file named "compare.dat".
Includes utility functions like deleting stored data.
This program can be a useful tool for users looking to compare exchange rates across different financial apps and identify the one that offers the best value.

## C Task Manager (TaskList.c)

This is a high-performance C program designed for efficient task management through a professional terminal-based interface. It utilizes advanced ANSI escape sequences to provide a structured, color-coded dashboard that helps users organize their daily activities with minimal resource consumption.

**Key features:**

Dynamic Categorization: Automatically filters and displays tasks into three priority-based sections: "Priority" (Urgent), "General Tasks," and "Done/Finished."

ANSI-Powered UI: Features a non-linear, coordinate-based rendering system that creates a modern dashboard layout with professional color coding and text styles.

Memory & CPU Optimization: Engineered for maximum efficiency using unsigned char for state management and direct terminal control sequences, bypassing heavy system calls.

Persistent Data Storage: Implements a robust save/load system using the TaskList.dat file, ensuring task descriptions and statuses are preserved across sessions.

Task Lifecycle Management: Allows users to easily add new tasks, elevate them to priority status, mark them as completed, or perform bulk data deletions.

Cross-Platform Performance: Built to be fully portable and lightweight, offering a fast and responsive experience on Windows, Linux, and macOS terminals.

This program is an excellent tool for users who need a lightweight, fast, and visually organized way to manage their "To-Do" lists directly from the command line.
